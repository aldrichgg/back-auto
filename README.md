# AutoEquity — Apex Capital Investment Platform

## Visão Geral

A **AutoEquity by Apex Capital** é uma plataforma mobile-first de investimento em frações de automóveis raros, hipercarros de coleção e veículos de competição histórica. A experiência combina a sofisticação de um family office com a agilidade de uma fintech de nova geração.
